# X-Ray - Company Profile

Website resmi Company Profile untuk **X-Ray**, dirancang untuk memberikan informasi yang jelas, modern, dan interaktif mengenai perusahaan, visi misi, layanan, dan kontak kepada klien atau publik.

🌍 **Live Demo:** [https://frontend-x-ray.vercel.app/](https://frontend-x-ray.vercel.app/)

---

## 🚀 Fitur Utama

*   **Desain Responsif:** Tampilan yang optimal di semua perangkat (Desktop, Tablet, dan Mobile).
*   **Performa Cepat & SEO Friendly:** Dioptimalkan untuk kecepatan pemuatan halaman dan mesin pencari.
*   **Informasi Layanan:** Menampilkan detail produk atau jasa yang ditawarkan oleh perusahaan.
*   **Navigasi Interaktif:** Transisi halaman yang mulus dan *user experience* (UX) yang intuitif.
*   **Halaman Kontak:** Memudahkan klien untuk terhubung langsung dengan tim (terintegrasi dengan form email/WhatsApp).

## 🛠️ Teknologi yang Digunakan

*(Silakan sesuaikan bagian ini dengan teknologi yang Anda gunakan)*

*   **Frontend Framework:** React.js / Next.js / Vue.js
*   **Styling:** Tailwind CSS / Bootstrap / SASS
